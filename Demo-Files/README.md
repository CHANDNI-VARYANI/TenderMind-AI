# TenderMind AI Demo

## Overview

This folder contains sample files used to demonstrate the complete workflow of TenderMind AI. These files showcase how the platform processes tender documents, evaluates vendor submissions, and generates explainable procurement decisions.

## Contents

- **demo_tender.txt** – Sample tender document containing eligibility criteria and procurement requirements.
- **bidder1_apex.txt** – Sample submission from Vendor 1.
- **bidder2_cheap.txt** – Sample submission from Vendor 2.
- **bidder3_kaveri.txt** – Sample submission from Vendor 3.

## Demo Workflow

1. Upload the sample tender document.
2. Extract eligibility criteria using AI.
3. Upload vendor documents.
4. Compare all vendors against the tender requirements.
5. Generate eligibility results and AI recommendations.
6. Review the final evaluation report.

## Purpose

These demo files are provided for demonstration, testing, and evaluation purposes only. They help illustrate the functionality of TenderMind AI and do not represent real procurement documents or actual vendors.
