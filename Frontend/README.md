# TenderMind AI Frontend

## Overview

The frontend of TenderMind AI provides an intuitive and user-friendly interface for procurement officers to upload tender documents, evaluate vendor submissions, review AI-generated insights, and generate procurement reports. It is designed to simplify complex procurement workflows while ensuring transparency and ease of use.

## Features

- User-friendly dashboard
- Tender document upload
- Vendor document submission
- AI evaluation results
- Explainable decision interface
- Vendor Performance & Reliability Score (VPRS)
- Procurement reports
- Analytics and insights
- Responsive design

## Workflow

1. Officer Login
2. Upload Tender Document
3. View Extracted Tender Criteria
4. Upload Vendor Documents
5. Review AI Evaluation
6. Verify Eligibility
7. Generate Final Report

## Technology Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Axios

## User Interface

The frontend is designed to provide a simple and efficient procurement experience by enabling officers to:

- Upload and manage tender documents
- Review extracted eligibility criteria
- Compare vendor submissions
- View AI-generated recommendations with explanations
- Generate procurement reports
- Monitor procurement analytics
